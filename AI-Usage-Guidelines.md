# AI Usage Guidelines

## What I Learned

I learned that AI tools can be useful for improving productivity, especially for tasks such as summarising information, brainstorming ideas, explaining technical concepts, checking writing, and helping with repetitive work.

However, AI should not be treated as a source that is always correct. AI can sometimes provide incorrect, outdated, incomplete, or misleading information. It is important to understand the output and check it before using it in professional work.

## Benefits of Using AI

Some useful ways AI can help in a professional setting include:

- Explaining unfamiliar technical topics
- Helping with research and brainstorming
- Summarising long information
- Improving the clarity of written work
- Helping identify possible problems in documents or code
- Reducing time spent on repetitive tasks

Using AI can save time, but the final responsibility for the work still belongs to me.

## Risks of Using AI

There are also risks when using AI tools at work. One important risk is accidentally sharing confidential or sensitive information.

I should not enter information such as:

- Passwords or authentication codes
- Personal information about users or employees
- Confidential company documents
- Internal security information
- Private customer or user data
- API keys, tokens, or other secrets
- Information that I am not authorised to share

Before using an AI tool, I should consider whether the information I am entering is appropriate to share with that service.

## Checking AI-Generated Information

I learned that AI-generated information should be reviewed before being used for professional work.

For important information, I should:

1. Check the original source where possible.
2. Compare important facts with trusted sources.
3. Check dates and figures instead of assuming they are correct.
4. Make sure the output actually answers the task.
5. Review the response for missing context or incorrect assumptions.
6. Use my own judgement before including the information in a report or decision.

I should not use an AI response as the only source for an important security or business decision.

## When I Should Use AI

I can use AI when it helps me understand something, organise my thoughts, improve writing, brainstorm ideas, or speed up a task that I still understand and can review myself.

For example, if I am learning about a technical security concept, I can ask AI to explain it in simpler terms and then verify the important information using reliable sources.

## When I Should Rely on My Own Skills

I should rely on my own judgement when making decisions that require knowledge of the company's policies, security requirements, or confidential information.

I should also avoid using AI as a replacement for learning. If I use AI to generate an answer or code, I should understand what it is doing rather than simply copying the result.

## Practical AI Task

For this task, I used an AI tool to help improve the wording and structure of a written reflection.

The AI helped make the content clearer and organise the information into sections. However, I reviewed the generated content myself and made changes where needed. I also checked that the information matched the actual task and did not include confidential company information.

This showed me that AI is more useful as an assistant rather than something that should completely replace my own work.

## How I Will Avoid Over-Reliance

To avoid depending too much on AI, I will try to understand the problem myself before asking AI for an answer.

When I use AI, I will:

- Think about the problem before asking for an answer.
- Use AI to support my understanding rather than blindly copying its output.
- Check important information independently.
- Edit the output so that it actually matches my work.
- Make sure I can explain the final result myself.

## Data Privacy

When using AI tools at Focus Bear, I will make sure that I do not share confidential information unless the tool and the company policy specifically allow it.

If I need help with a problem involving sensitive information, I can remove or replace identifying details with safe placeholders where possible.

I will also avoid putting passwords, API keys, private user information, internal documents, or other sensitive data into AI tools.

## Best Practice I Will Follow

The main best practice I will follow is:

> **Use AI as an assistant, not as the final decision-maker.**

I will review and fact-check AI-generated information before using it, and I will make sure that I am not sharing confidential or sensitive company information.

## Reflection

The main thing I learned is that using AI responsibly is not just about getting useful answers. It is also about knowing what information is safe to share and being able to judge whether the output is actually correct.

AI can save time and help me learn faster, but I should still understand the work and take responsibility for the final result. Going forward, I will use AI when it genuinely helps with a task, while keeping data privacy and critical thinking in mind.
